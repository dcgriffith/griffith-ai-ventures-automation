# Automation Trust Levels

## Green — Autonomous
- Read authorized sources
- Generate reports and summaries
- Create drafts and internal tasks
- Classify support requests
- Monitor analytics

## Amber — Restricted
- Publish public social posts
- Send customer emails
- Change subscription records
- Update ITSM incident priorities
- Modify test identity accounts

## Red — Human-controlled
- Financial transfers and refunds
- Production user deletion or access revocation
- Security policy changes
- Production incident containment
- Credential and secret rotation
