# Workflow 03 — Security asset → Gumroad offer

**ID:** `wf-sec-asset-to-offer`  
**Trust:** Green (outline/draft) → Amber (publish product)  
**Agents:** Product Development + IAM / SOC + Revenue Intelligence  
**Orchestration:** Manual run or biweekly schedule

## Steps

1. Inventory GitHub security assets (Threat Analyzer, Detection Lab, Entra JML/PAM).
2. Select one SKU (see `business-operations/digital-products/SKU-001-iam-jml-checklist.md`).
3. Produce outline + draft content structure.
4. Owner builds PDF (Canva/export) and lists on Gumroad (Amber).
5. Marketing Agent drafts launch Note/Medium post (Green → Amber publish).

## Success metric

SKU live on Gumroad (yes/no); first sale tracked when it occurs.
