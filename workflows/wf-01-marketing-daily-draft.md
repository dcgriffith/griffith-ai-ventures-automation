# Workflow 01 — Marketing daily draft

**ID:** `wf-marketing-daily-draft`  
**Trust:** Green (draft) → Amber (publish by owner)  
**Agent:** Marketing Intelligence  
**Orchestration:** Grok daily schedule; optional n8n file-to-GitHub later

## Steps

1. Generate one Substack Note draft (80–200 words).
2. Prefer themes: Substack learning experiences, practical AI, cybersecurity labs.
3. Provide 3 alternative openers.
4. Owner personalizes and publishes (Amber).
5. Owner logs title + date in `business-operations/marketing/publish-log.md` (create if missing).

## Success metric

Notes published per week (count only — no fabricated engagement).
